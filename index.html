카드 5 확인 방법

  1. 어디로 가나요? 이 페이지의 실제 공개 환율 조회 영역을 확인합니다.
  2. 무엇을 하나요? 서로 다른 KST 날짜에 같은 공개 원천을 다시 조회합니다.
  3. 무엇이 보이면 통과인가요? 실제 날짜 기록이 2건이고, 각 기록의 원천·시각·값·단위와 저장값·화면값이 일치하며, 어제 대비 계산값도 일치하면 통과입니다.
  4. 안 될 때 무엇이 보이나요? 실제 기록이 2건이 되지 않거나, 원천값·저장값·화면값이 서로 다르면 해당 항목을 다시 확인합니다.
